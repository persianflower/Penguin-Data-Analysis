# Penguin-Data-Analysis
Analysis of dataset on penguin species on R

The use case done in this assignment is: “Analysis of species of penguins”. It makes use of one of the default datasets provided in R called “penguins” for the same.
The objective of this case study is to understand and predict the species of penguin based on various features provided. The same was achieved via different classification machine learning algorithms to better understand and provide analytics via accurate readings.
Various visualization techniques were used so as to better understand the dataset as well as its various features. With the help of these visualizations the algorithm was also chosen.
